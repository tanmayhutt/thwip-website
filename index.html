CORE CAPABILITIES

Built for Real Developer Workflows

Every feature designed to eliminate context loss, tool fragmentation, and rate limit friction.

System-Wide Auto-Detection

Scans your PATH, macOS applications, and VS Code extensions to discover installed tools (Claude Code, Antigravity, Codex, Aider, Ollama) and automatically reads configured credentials.

Zero Context Loss Portability

When switching models with /switch or Ctrl+S, your entire message history, reasoning deltas, file diffs, and pending tasks hand off directly to the new model.

Automatic Rate-Limit Failover

Catches HTTP 429 quota exhaustion errors mid-stream and offers instant one-key switching to ready fallback models so your coding session never breaks.

Dynamic UI (DUI) Adaptation

The terminal styling adapts dynamically to active provider colors, displays verified capabilities, and highlights warnings if an agent lacks file editing or execution power.

Shared Tool Layer

Every connected agent gains unified access to safe file editing, sandboxed Python and Node execution, shell terminal commands, and Git operations within project bounds.

Session Persistence

Save and resume work sessions with /session save and /session load. Complete with token tracking, cumulative cost estimations, and history logs.

TERMINAL SHORTCUTS

Command Cheatsheet

Essential slash commands and ergonomics for keyboard-first developers.

Command / Shortcut Description Example
/switch [agent] [model] Hot-swap active model mid-conversation with zero context loss /switch google gemini-2.5-pro
/agents Display all discovered local agents, subscription tier, and capabilities /agents
/models [agent] List available models, context window limits, and pricing /models openai
/limits Inspect live session tokens, cumulative cost, and quota metrics /limits
/detect Re-scan system for newly installed coding agents or CLI binaries /detect
/session save [name] Persist current conversation, file modifications, and state to disk /session save auth-refactor
/session load <name> Restore saved conversation and seamlessly resume coding /session load auth-refactor
Ctrl + S Interactive agent switch prompt shortcut Hotkey
Ctrl + T Display current agent status and token counters Hotkey
Ctrl + H View message history with provider attribution badges Hotkey
