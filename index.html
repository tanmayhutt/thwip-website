What is thwip?

thwip is an open source coding agent multiplexer that connects all local AI models into a unified terminal workspace.

  • [*]
    Auto-Detection

    Discovers CLI agents (claude, agy, gemini, codex, aider, ollama), IDE apps (Cursor, Windsurf), and VS Code extensions.

  • [*]
    Zero Context Loss

    Switch between Claude, Gemini, OpenAI, or Ollama mid-project without losing conversational memory, reasoning, or files.

  • [*]
    Rate Limit Failover

    Detects HTTP 429 errors or quota exhaustion and prompts instant one-key switching to ready fallback models.

  • [*]
    Shared Tool Layer

    Every connected agent gains safe file editing, sandboxed Python and Node execution, shell commands, and Git ops.

  • [*]
    Dynamic DUI

    Terminal interface adapts its theme colors, headers, and status bars to match the active provider branding and real capabilities.

  • [*]
    Local & Offline

    Integrates directly with local Ollama instances for unlimited, offline coding with zero API keys required.
