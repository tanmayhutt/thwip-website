# thwip-website

Marketing landing page and documentation portal for thwip (Universal Coding Agent Multiplexer).

## Tech Stack

- Vanilla HTML5, modern CSS3, JavaScript (ES modules)
- Vite for local development and optimized static bundling
- Dark theme styling with interactive terminal simulation

## Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
